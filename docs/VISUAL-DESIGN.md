# Visual direction — November 2026

The existing forest-green identity stays. The memorable visual is a signal-board diagram that explains the two actual workflows and their shared execution ledger. Exploring it changes the explanation, never starts an inference or invents a run.

Palette: forest #173a31, ink #182327, paper #f5f6f0, lime #c9ed80, muted slate #536268, evidence blue #365e8b. Typography remains the local system sans with a restrained, readable scale; no external font or tracking request. The brand mark is an M-shaped trace with three connection nodes, readable at favicon size.

Hero: left-aligned question/action, right a responsive circuit map. Workflow forms remain the main work surface. Icons express knowledge, source retrieval, access and stored receipts. Empty, locked, loading, insufficient-context and failure states are distinct. The public diagram is explicitly an architecture explanation rather than simulated execution.

Interaction: useful user-triggered highlighting, keyboard-operable flow selectors and sample questions, minimum touch targets, visible focus and reduced-motion support. No automatic decorative animation. Execution records get human-readable content with optional technical JSON and an explicit export action.
