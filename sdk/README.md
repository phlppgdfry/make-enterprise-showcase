# Historical Make Endpoints SDK sketches

The `call-endpoint.js` and `call-endpoint.ts` files are **unverified historical API sketches**. They are not part of the tested agent-workbench runtime. Their imports, call signatures, connection IDs and error handling have not been checked against the current SDK. Do not run them or treat them as production examples without resolving the installed SDK documentation and real endpoint schemas.

Use the working [authenticated gateway](../scripts/server.js) and [current Make integration guide](../docs/MAKE-AI-AGENTS.md) for this release. Confidential logging settings and an idempotency key do not, by themselves, establish legal compliance or exactly-once effects.
